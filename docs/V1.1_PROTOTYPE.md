# NobiDownloader V1.1 Prototype

This prototype is a **UI/UX exploration built on the working V1 Beta backend**.

## Design direction
- Calm, pastel, eye-comfort workspace
- Sidebar navigation: Home, Downloads, Playlists, Settings
- Spacious cards and low-contrast surfaces
- Serif accent typography for warmth
- One clear workflow: URL → Analyze → Format → Location → Download
- Real V1 backend endpoints remain in use; no fake download/status data is generated

## Prototype screens
- **Home:** real media/playlist analysis, real format selection, real folder picker, real download flow and progress modal.
- **Downloads:** reads `/api/downloads` and opens real files through Explorer.
- **Playlists:** groups downloaded files by their real playlist folder.
- **Settings:** switches the five eye-comfort themes.

## V1 functionality preserved
The prototype keeps the V1 Beta backend, including yt-dlp + FFmpeg, strict resolution presets, MP3 mode, native Windows folder selection, playlist detection, playlist folder naming, storage/download APIs, and same-process server lifetime.

This is intentionally a prototype so the visual system can be tested before the V1.1 implementation is frozen.


### Smart download meter change
The temporary network-speed/ETA/size preflight experiment was removed. Download progress now stays simple and reliable: live percentage from yt-dlp during transfer, with the actual completed file size shown after the download finishes.

### Click feedback
A global click sound is applied to interactive buttons, links, navigation items, source chips, format choices, theme controls, and modal actions. Success/error feedback remains distinct for completed or failed operations.

## Dashboard controls update
- Dashboard now surfaces Local Server status and a Close Server action.
- Dashboard now places the GitHub star request near the top for visibility.
- URL analysis has an explicit Cancel analysis action using AbortController.
- Download modal has an explicit Cancel Download action backed by `/api/jobs/{job_id}/cancel`.

## V1.1 Branding

The V1.1 prototype now uses the NobiDownloader brand mark throughout the web app, including the sidebar, URL-analysis animation, and browser favicon. The supplied brand artwork is bundled under `app/frontend/assets/`.
